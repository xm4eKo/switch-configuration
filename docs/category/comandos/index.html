Comandos

Comandos interesantes y útiles para la configuración de switches

📄️ Seguridad y Acceso

✅ `banner motd` -> Muestra un mensaje de advertencia cuando alguien accede al switch. Es importante legalmente para avisar que es un sistema privado.

📄️ Red y Conectividad

✅ `lldp` -> Habilita LLDP (Link Layer Discovery Protocol), que permite descubrir qué otros dispositivos están conectados (útil para gestionar la red).

📄️ Rendimiento y Calidad de servicio

✅ `qos queue-profile` + `schedule-profile` -> Configura la Calidad de Servicio (QoS): garantiza ancho de banda para tráfico sensible como voz (VoIP).

📄️ Prevención de problemas

✅ `loop-protect` -> Detecta y mitiga bucles de red, que pueden colapsar el tráfico.

📄️ Otros interesantes

✅ `cli-session timeout 43200` -> Establece cuanto tiempo puede durar una sesión CLI (12 horas).
