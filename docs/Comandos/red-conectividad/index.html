🌐 Red y conectividad

✅ lldp -> Habilita LLDP (Link Layer Discovery Protocol), que permite descubrir qué otros dispositivos están conectados (útil para gestionar la red).

✅ lacp hash l4-src-dst -> Configura cómo se hace el balanceo de carga en enlaces agregados (usa capa 4, es decir, puertos TCP/UDP).

✅ ntp server + ntp enable -> Sincroniza el reloj del switch con un servidor horario externo (importantísimo para logs y auditorías).

✅ ip dns domain-name + ip dns server-address -> Configura DNS para que el switch pueda resolver nombres de dominio.

✅ interface vlan 1 -> Indica que la VLAN 1 obtendrá IP por DHCP.

✅ vlan -> Define todas las VLANs usadas, organizando el tráfico de red de forma lógica.
